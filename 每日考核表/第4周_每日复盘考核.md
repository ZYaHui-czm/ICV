## 🗓️ 第22天 <a id="day22"></a>

**主题**：collections — Counter + defaultdict

**学习内容**：
```python
from collections import Counter, defaultdict

# Counter — 自动计数器
words = ["apple", "banana", "apple", "orange", "banana", "apple"]
c = Counter(words)
print(c)                    # Counter({'apple': 3, 'banana': 2, 'orange': 1})
c2 = Counter("abracadabra") # Counter({'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1})
print(c["apple"])           # 3
print(c["pear"])            # 0（不存在的键返回0，不报错！）
print(c.most_common(2))     # [('apple', 3), ('banana', 2)]  前2名
c3 = Counter(["apple", "pear"])
print(c + c3)               # Counter({'apple': 4, 'banana': 2, 'orange': 1, 'pear': 1})

# defaultdict(int) — 默认值 0
dd = defaultdict(int)
dd["apple"] += 1    # 键不存在 → 自动创建，默认值0 → 0+1=1

# defaultdict(list) — 默认值空列表
students = defaultdict(list)
students["一班"].append("小明")

# defaultdict(set) — 防重复
tags = defaultdict(set)
tags["Python"].add("编程语言")
tags["Python"].add("编程语言")   # 重复不添加

# 分组对比：普通字典 vs defaultdict
groups = defaultdict(list)
for word in words:
    groups[word[0]].append(word)
```

**对比表**：
| | `dict` | `defaultdict` | `Counter` |
|--|--------|--------------|-----------|
| 访问不存在键 | KeyError | 自动创建默认值 | 返回 0 |
| 适用场景 | 一般键值对 | 分组/归类 | 计数/频率统计 |

**口诀**：Counter自动计次数，most_common看排名；不存在键返回0；defaultdict带默认，分组归类最拿手

**得分**：84/100 🟢

---

### 一、名词解释（每题5分，共20分）
1. **Counter vs 普通字典优势**     //作答：简洁代码 🟡 补充：不存在键返回0不报错、most_common()一条龙
2. **defaultdict(list) vs {}**     //作答：前者带默认值不触发KeyError而是创建空列表 ✅

**主题**：requests — HTTP 请求库

**学习内容**：
```python
import requests

# GET 请求
response = requests.get("https://api.github.com")
print(response.status_code)    # 200 状态码
print(response.text)           # 原始文本
print(response.json())         # JSON → 字典

# 带参数
params = {"q": "python", "sort": "stars"}
response = requests.get("https://api.github.com/search/repositories", params=params)

# 状态码速查：200成功 404找不到 500服务器错误 403没权限

# 处理响应
response.raise_for_status()    # 不成功直接抛异常

# POST 请求
data = {"name": "小明", "score": 95}
response = requests.post("https://httpbin.org/post", json=data)
form_data = {"username": "admin"}
response = requests.post("https://httpbin.org/post", data=form_data)

# 异常处理 + 超时
try:
    response = requests.get("https://api.github.com", timeout=5)
    response.raise_for_status()
    data = response.json()
except requests.exceptions.Timeout:
    print("请求超时！")
except requests.exceptions.ConnectionError:
    print("网络连接失败！")
except requests.exceptions.HTTPError as e:
    print(f"HTTP 错误：{e}")
except requests.exceptions.RequestException as e:
    print(f"其他错误：{e}")
```

**口诀**：requests.get发请求，.json()解析返回值；status_code看状态，200成功404找不到；timeout设超时防卡死，raise_for_status抛异常

## 🗓️ 第24天 <a id="day24"></a>

**主题**：上下文管理器 — `with` 背后的原理

**学习内容**：
```python
# 自定义上下文管理器 — 用类实现
class Timer:
    def __enter__(self):
        import time
        self.start = time.time()
        print("开始计时...")
        return self           # 返回给 as 后面的变量
    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        elapsed = time.time() - self.start
        print(f"计时结束：{elapsed:.2f}秒")
        return False          # False=不吞异常，True=吞掉异常

with Timer() as t:
    total = sum(range(10000000))

# __exit__ 三个参数：exc_type异常类型、exc_val异常值、exc_tb traceback

# 用 contextmanager 装饰器 — 生成器写法
from contextlib import contextmanager

@contextmanager
def timer():
    import time
    start = time.time()
    print("开始计时...")
    yield                    # yield前=__enter__，yield后=__exit__
    elapsed = time.time() - start
    print(f"计时结束：{elapsed:.2f}秒")

# 实战：临时切换目录
@contextmanager
def cd(path):
    old = os.getcwd()
    os.chdir(path)
    try:
        yield
    finally:
        os.chdir(old)        # 无论如何都会切回去

# 数据库连接
class Database:
    def __enter__(self):
        print("连接数据库...")
        return self
    def __exit__(self, *args):
        print("断开连接")

# 吞掉异常
@contextmanager
def ignore_error():
    try:
        yield
    except Exception as e:
        print(f"忽略错误：{e}")
```

**口诀**：with进来__enter__，出去__exit__自动调；类写两方法，装饰器用yield分两半；yield前是进入，yield后是收尾

**得分**：91/100 🟢（修复后+20分）

---

### 一、名词解释（每题5分，共20分）
1. **`__enter__` 和 `__exit__` 什么时候执行**     //作答：前者进入时执行，后者结束时执行（无论中间是否崩溃都执行） ✅
2. **`@contextmanager` 中 `yield` 的作用**     //作答：分割为enter和exit两部分，yield前enter，yield后exit ✅
3. **`__exit__` 返回 True/False 的区别**     //作答：True吞掉异常程序不崩溃，False不吞异常向外传递 ✅
4. **`with open()` 比手动 `f.close()` 更安全的原因**     //作答：前者自动执行f.close，后者有时忘记 ✅

class FileLogger:
    def __init__(self, filename):

        self.filecontext = None
