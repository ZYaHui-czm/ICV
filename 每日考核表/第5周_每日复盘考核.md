## 🗓️ 第29天 <a id="day29"></a>

**主题**：项目结构 + 模块化设计

**学习内容**：
```
标准 Python 项目结构：
my_project/
├── README.md                 # 项目说明
├── requirements.txt          # 依赖清单
├── .gitignore                # git 忽略文件
├── my_project/               # 主包
│   ├── __init__.py           # 文件夹变"包"的标记
│   ├── main.py               # 程序入口
│   ├── config.py             # 配置
│   ├── models.py             # 数据模型
│   ├── utils.py              # 工具函数
│   └── services/             # 子模块
│       ├── __init__.py
│       └── user_service.py
└── tests/                    # 测试
    └── test_main.py
```

```python
# __init__.py — 文件夹变身"包"
from my_project import models, utils
from my_project.services import user_service

# if __name__ == "__main__" — 双重身份
def add(a, b):
    return a + b
if __name__ == "__main__":
    print("直接运行时执行")     # import 时这里不执行

# 绝对导入 vs 相对导入
from my_project import models              # 绝对（完整包名）
from .models import User                   # 相对（同包用.）

# requirements.txt 版本管理
requests==2.31.0       # == 精确版本
pandas>=2.0.0          # >= 最低版本
pytest~=8.0            # ~= 兼容8.x
```

**口诀**：__init__.py是门牌，文件夹变包；if __name__双身份，直接跑就执行，import不执行；绝对导入用全名，相对导入用点；main.py只指挥，功能分文件放；requirements锁版本

**得分**：96/100 🟢

### 一、名词解释（每题5分，共20分）
1. **`__init__.py` 作用**     //作答：标识该目录为包，方便后续导入 ✅
2. **`if __name__` 解决问题**     //作答：防止目标文件作为导入文件时运行其代码 ✅
3. **绝对 vs 相对导入**     //作答：绝对导入需完整包名，包名修改会异常；相对导入简洁，包名修改不影响 ✅
4. **`==` vs `~=`**     //作答：==具体版本，~=兼容版本如~=8.0兼容8.x ✅

### 四、手写代码（30分）
**题目**：重构计算器 — operations.py + main.py + __init__.py
```python
# operations.py
def add(a, b): return a + b
def subtract(a, b): return a - b
def multiply(a, b): return a * b
def divide(a, b):
    if b == 0:
        raise ValueError        # ✅ 除零处理
    return a / b

# main.py
from operations import *        # ⚠️ 通配符导入不推荐
def get_nums():
    while True:
        try:
            parts = input("请输入").split()
            if len(parts) != 3:
                print("请输入三部分：数字，运算符，数字")
                continue
            a, op, b = parts
            return float(a), op, float(b)
        except ValueError:
            print("无效输入，请重新输入")

if __name__ == "__main__":
    a, op, b = get_nums()
    if op == '-': result = subtract(a, b)
    elif op == '+': result = add(a, b)
    elif op == '*': result = multiply(a, b)
    elif op == '/': result = divide(a, b)
    else: print("请输入正确的运算符")
    print(result)
```
✅ 输入验证+异常处理+分派逻辑完整 🟡 通配符导入应改为明确列出
