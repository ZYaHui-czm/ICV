```
标准 Python 项目结构：

├── requirements.txt          # 依赖清单
├── .gitignore                # git 忽略文件

```

```python
# __init__.py — 文件夹变身"包"
from my_project import models, utils
from my_project.services import user_service

# if __name__ == "__main__" — 双重身份
def add(a, b):
    return a + b
if __name__ == "__main__":
    print("直接运行时执行")     # import 时这里不执行

# 绝对导入 vs 相对导入

from .models import User                   # 相对（同包用.）

# requirements.txt 版本管理
requests==2.31.0       # == 精确版本

```

**口诀**：__init__.py是门牌，文件夹变包；if __name__双身份，直接跑就执行，import不执行；绝对导入用全名，相对导入用点；main.py只指挥，功能分文件放；requirements锁版本

```python
# operations.py
def add(a, b): return a + b
def subtract(a, b): return a - b
def multiply(a, b): return a * b
def divide(a, b):
    if b == 0:
        raise ValueError        # ✅ 除零处理
    return a / b

# main.py
from operations import *        # ⚠️ 通配符导入不推荐
def get_nums():
    while True:
        try:
            parts = input("请输入").split()
            if len(parts) != 3:
                print("请输入三部分：数字，运算符，数字")
                continue
            a, op, b = parts
            return float(a), op, float(b)
        except ValueError:
            print("无效输入，请重新输入")

if __name__ == "__main__":
    a, op, b = get_nums()
    if op == '-': result = subtract(a, b)
    elif op == '+': result = add(a, b)
    elif op == '*': result = multiply(a, b)
    elif op == '/': result = divide(a, b)
    else: print("请输入正确的运算符")
    print(result)
```
✅ 输入验证+异常处理+分派逻辑完整 🟡 通配符导入应改为明确列出

## 🗓️ 第30天 <a id="day30"></a>

**主题**：设计模式 — 单例 + 工厂 + 装饰器

**学习内容**：
```python
# 单例模式 — 全程序只有一个实例
class Logger:
    _instance = None
    def __new__(cls, *args, **kwargs):
        # __new__ 在 __init__ 之前，负责创建对象
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance        # 每次返回同一个
    def log(self, msg):
        print(f"[LOG] {msg}")

l1 = Logger(); l2 = Logger()
print(l1 is l2)     # True

# 工厂模式 — 按需生产对象
class Circle:
    def draw(self): return "绘制圆形"
class Square:
    def draw(self): return "绘制方形"

class ShapeFactory:
    @staticmethod
    def create(shape_type):
        shapes = {"circle": Circle, "square": Square}
        cls = shapes.get(shape_type)
        if cls is None:
            raise ValueError(f"未知形状：{shape_type}")
        return cls()

shape = ShapeFactory.create("circle")
print(shape.draw())   # 绘制圆形

# 装饰器模式 — 给对象加功能（不用继承）
class Coffee:
    def cost(self): return 10
    def desc(self): return "咖啡"

class CoffeeDecorator:
    def __init__(self, coffee):
        self._coffee = coffee
    def cost(self): return self._coffee.cost()
    def desc(self): return self._coffee.desc()

class Milk(CoffeeDecorator):
    def cost(self): return self._coffee.cost() + 2
    def desc(self): return self._coffee.desc() + "，加牛奶"

class Sugar(CoffeeDecorator):
    def cost(self): return self._coffee.cost() + 1
    def desc(self): return self._coffee.desc() + "，加糖"

coffee = Sugar(Milk(Coffee()))
print(coffee.desc())   # 咖啡，加牛奶，加糖
print(coffee.cost())   # 13
```

**三模式对比**：
| 模式 | 解决什么问题 | 一句话 |
|------|------------|--------|
| 单例 | 全局只需一个对象 | 全程序只有一个 |
| 工厂 | 创建对象逻辑集中 | 按需生产 |
| 装饰器 | 动态加功能不修改原类 | 层层贴贴纸 |

**口诀**：单例模式全局一，__new__里拦创建；工厂模式集中管，按名造对象；装饰器模式贴贴纸，功能层层加

**得分**：99/100 🟢🏆

2. **工厂模式解决什么**     //作答：解决需要反复创建实例的问题，将创建实例封装起来 ✅

### 四、手写代码（30分）
**题目**：工厂模式实现通知系统 Email/SMS/Push + NotifierFactory
```python
class EmailNotifier:
    def send(self, msg): print(f'email:{msg}')
class SMSNotifier:
    def send(self, msg): print(f'SMS: {msg}')
class PushNotifier:
    def send(self, msg): print(f'Push :{msg}')

class NotifierFactory:
    _PushType = {"email": EmailNotifier, "sms": SMSNotifier, "push": PushNotifier}
    @classmethod                    # 👏 自己用classmethod！
    def create(cls, notify_type):
        push_type = cls._PushType.get(notify_type)
        if push_type is None:
            raise ValueError(f'未知通知类型:{notify_type}')
        return push_type()
```
✅ 三通知类+工厂+ValueError全对 👏 @classmethod 用得很好 30/30

## 🗓️ 第31天 <a id="day31"></a>

**主题**：SOLID 设计原则

**学习内容**：
```python
# S 单一职责 — 一个类只干一件事
class UserStorage:       # 只管存
    def save(self, user): ...
class EmailService:      # 只管发邮件
    def send(self, user): ...
class ReportGenerator:   # 只管报表
    def generate(self, user): ...

# O 开闭原则 — 对扩展开放，对修改关闭
class Shape:
    def area(self): raise NotImplementedError
class Circle(Shape):
    def __init__(self, r): self.r = r
    def area(self): return 3.14 * self.r ** 2
class Square(Shape):
    def __init__(self, side): self.side = side
    def area(self): return self.side ** 2
# 新增形状只需新写类，calculate_area 不用动
def calculate_area(shape):
    return shape.area()

# L 里氏替换 — 能用父类的地方换成子类也没问题
class Bird:
    def move(self): return "移动"
class FlyingBird(Bird):
    def fly(self): return "飞"
class Penguin(Bird):     # 企鹅不会飞，不继承fly
    def swim(self): return "游"

# I 接口隔离 — 别让调用方依赖用不到的东西
class Coder:
    def code(self): ...
class Chef:
    def cook(self): ...

# D 依赖倒置 — 依赖抽象，不依赖具体
class MessageSender:     # 抽象接口
    def send(self, msg): raise NotImplementedError
class EmailSender(MessageSender):
    def send(self, msg): ...
class SMSSender(MessageSender):
    def send(self, msg): ...

class NotificationService:
    def __init__(self, sender: MessageSender):  # 依赖抽象
        self.sender = sender
    def notify(self, msg):
        self.sender.send(msg)
# 换SMS只需换传入对象，NotificationService不用改
```

**口诀**：S单职一兼多职，改了这动那；O开闭扩展开放，加新不改旧；L里氏子可替父，别让父失灵；I接口小而专，别被迫实现；D依赖倒置靠抽象，换实现不改高层

**得分**：94/100 🟢

### 四、手写代码（30分）
**题目**：重构OrderProcessor — 依赖倒置+单一职责+开闭
```python
from abc import ABC, abstractmethod

# 抽象接口
class Logger(ABC):
    @abstractmethod
    def log(self, order): ...
class DiscountStrategy(ABC):
    @abstractmethod
    def calculate(self, amount): ...
class MessageSender(ABC):
    @abstractmethod
    def send(self, message): ...

# 具体实现
class FileLogger(Logger):
    def log(self, order): print(f'[日志]{order}')
class DiscountOver100(DiscountStrategy):
    def calculate(self, amount):
        if amount > 100: return amount*0.9
        return amount
class DefaultPay(DiscountStrategy):
    def calculate(self, amount): return amount
class EmailSend(MessageSender):
    def send(self, message): print(f'email:{message}')

# 依赖注入
class OrderProcessor:
    def __init__(self, logger: Logger, discount: DiscountStrategy, sender: MessageSender):
        self.logger = logger
        self.discount = discount
        self.sender = sender
    def process(self, order):
        self.logger.log(f'处理订单{order["id"]}')
        final_price = self.discount.calculate(order['total'])
        self.sender.send(f'订单{order["id"]}已处理,金额{final_price:.2f}')
        return final_price
```
👏 ABC + abstractmethod + 策略模式 + 依赖注入全部自用！超纲完成 30/30 🎉
